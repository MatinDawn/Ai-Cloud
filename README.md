# 待办清单

一个纯前端的待办清单（To-Do List）网页小工具，零后端、零构建、零依赖，浏览器直接打开即可使用。

## 简介

用单个 `index.html` 文件实现了一个简洁美观的待办清单应用。所有 CSS 和 JavaScript 均内嵌在 HTML 中，无需任何外部库或构建工具。数据通过浏览器 `localStorage` 自动保存，刷新页面后列表不会丢失。

## 功能

- **添加待办** — 在输入框中输入内容，点击「添加」按钮或按回车键即可添加
- **标记完成 / 取消完成** — 点击待办左侧的圆圈切换完成状态，完成后文字显示删除线
- **删除待办** — 点击右侧的 × 按钮删除单条待办
- **清除已完成** — 一键清除所有已完成的待办事项
- **数量统计** — 底部实时显示总数和未完成数量
- **本地持久化** — 使用 `localStorage` 保存数据，刷新/重开浏览器后自动恢复
- **中文界面** — 全中文 UI，简洁美观

## 运行方式

### 方式一：直接打开

双击 `index.html`，用任意现代浏览器打开即可。

### 方式二：本地服务器

```bash
cd todo-list
python3 -m http.server 8088
```

然后在浏览器中访问 `http://localhost:8088`。
